> ⚠️ **Important Note Before Opening the Power BI File (`.pbix`):**
> 
> After cloning or downloading the repository files to your local machine, you must update the data source file path(s) in Power BI. 
> 
> **How to update the source path:**
> 1. Open the `.pbix` file in Power BI Desktop.
> 2. Go to the **Home** tab and click on **Transform Data** > **Data source settings**.
> 3. Select the data source and click **Change Source...**
> 4. Browse and select the updated file path where you saved the dataset on your computer.
> 5. Click **Apply Changes** to refresh and load the data correctly.
